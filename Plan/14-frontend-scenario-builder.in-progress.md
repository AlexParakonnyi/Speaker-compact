# 14. Редактор сценариев

**Статус:** pending
**Обновлено:** 2026-07-27
**Проект:** frontend
**Зависит от:** 07, 12, 13

## Цель

Экран сборки сценария: выбор треков (из уже знакомой сетки плиток, план 13,
в режиме множественного выбора), порядок, задержка и громкость на каждый шаг,
сохранение как именованный пресет.

## Детали

1. **Выбор треков** — тот же грид плиток (план 13), но в режиме "выбора"
   (чекбоксы поверх плиток при входе в редактор сценария) вместо режима
   "управления файлами".
2. **Список шагов** — после выбора треков превращается в reorderable список
   (`Reorder.Group` из Framer Motion, drag-handle на каждом шаге), с двумя
   инлайн-контролами на шаг:
   - Слайдер громкости (0-100%, шаг из плана 07 `steps[i].volume`).
   - Задержка после предыдущего шага (числовой инпут + степпер, в секундах
     или минутах — предусмотреть переключение единиц, задержки могут быть от
     секунд до часов).
3. **Общая задержка перед стартом** (`startDelaySec` из плана 07) — отдельный
   контрол в шапке экрана редактора, не в списке шагов.
3.5. **Флажок "Зацикливать сценарий"** (`loop` из плана 07, подтверждено) —
   переключатель (`Switch`, не чекбокс — заметнее на мобильном) рядом с общей
   задержкой. По умолчанию выключен. Короткая подсказка под переключателем:
   "После последнего трека сценарий начнётся заново" — чтобы пользователь
   осознанно включал бесконечное воспроизведение (влияет на батарею).
4. **Сохранение** — имя сценария (текстовый инпут), кнопка "Сохранить как...".
   Список существующих сценариев — отдельная секция/экран для выбора
   готового (план 15 переиспользует этот список на экране активации).
5. **Валидация** — хотя бы один шаг обязателен для сохранения, задержки не
   отрицательные — простая клиентская валидация, серверная тоже не помешает
   (не доверять фронтенду на устройстве с ограниченными ресурсами тоже не
   стоит переусложнять валидацией — базовая достаточна).

## Открытые вопросы

- Единицы измерения задержки по умолчанию (секунды vs минуты vs часы) — не
  согласовано, возьму секунды с возможностью ввода "5м"/"1ч" как удобство,
  скорректировать при осмотре первого прототипа.

## Критерии готовности

- Можно собрать сценарий из 3+ треков, переставить местами, задать разные
  задержки/громкости, сохранить и увидеть в списке сценариев.
