# 13. Экран треков: плитки и картинки

**Статус:** pending
**Обновлено:** 2026-07-27
**Проект:** frontend
**Зависит от:** 04, 05, 06, 12

## Цель

Главный экран: треки в виде плиток (тайлов), с картинкой (или заглушкой),
названием, длительностью; фильтр/переключение по группам; действия
(переименовать, удалить, перенести в группу, прикрепить фото).

## Детали

1. **Сетка плиток** — адаптивная (`grid-cols-2` на узких экранах, больше на
   планшетах), картинка как фон плитки (`aspect-square` или `aspect-[4/3]`),
   название и длительность — оверлеем снизу (градиент для читаемости поверх
   фото, как в типичных медиатеках).
2. **Заглушка без фото** — не пустой квадрат, а что-то с намёком на аудио
   (иконка ноты/волны + акцентный цвет по хэшу имени файла, чтобы плитки без
   фото не выглядели одинаково-безликими).
3. **Прикрепление фото** — долгий тап/кнопка на плитке открывает bottom sheet
   с тремя вариантами (буфер обмена / камера / файл), см. план 06. Показать
   превью и кнопку "Сохранить" перед отправкой на устройство (дать
   возможность отменить/выбрать другое фото до аплоада).
4. **Группы** — горизontal-scroll чипов сверху экрана (по образцу
   Instagram/Stories-подобных фильтров), выбор группы фильтрует сетку.
   "Перенести в группу" — из контекстного меню плитки, список существующих
   групп + "Создать новую".
5. **Переименование/удаление** — контекстное меню (долгий тап или кнопка
   "⋮" на плитке), удаление — через `Dialog`-подтверждение.
6. **Долгая загрузка списка** (потенциально десятки треков с картинками) —
   предусмотреть скелетоны/лоадер, картинки — `loading="lazy"`.
7. **Превью-воспроизведение** (новое требование) — кнопка ▶/⏸ прямо на
   плитке (поверх картинки/заглушки), вызывает `POST /api/tracks/play` /
   `/stop` (план 04). Играет только один трек одновременно — при старте
   нового превью визуально сбросить состояние play-кнопки на плитке, где
   играло раньше (опрос `GET /api/status`-подобного эндпоинта или локальный
   state — решить при реализации). Учесть, что это отдельная функция от
   "добавить в сценарий" — не путать плей-превью с чекбоксами выбора треков
   в редакторе сценария (план 14).

## Критерии готовности

- На реальном мобильном устройстве, подключённом к AP, экран плиток
  отзывчивый, без дёрганий при скролле, действия (rename/delete/group/photo)
  работают end-to-end против реального API устройства.
