# 05. Группировка файлов через метаданные

**Статус:** done
**Обновлено:** 2026-08-09
**Проект:** device
**Зависит от:** 04

## Цель

Реализовать группировку треков через JSON-индекс на SD (согласованное решение,
см. `CLAUDE.md` §2.3), без реальных папок.

## Детали

1. Формат `/groups.json` на SD:
   ```json
   {
     "groups": ["Утро", "Вечер", "Праздник"],
     "assignments": { "track1.mp3": "Утро", "track2.wav": "Вечер" }
   }
   ```
   Трек без записи в `assignments` считается негруппированным ("Без группы").
2. API:
   - `GET /api/groups` — список групп + распределение треков.
   - `POST /api/groups/create` / `rename` / `delete` (при удалении группы —
     треки становятся негруппированными, не удаляются).
   - `POST /api/tracks/assign_group` — `{file, group}` — тот самый "перенос в
     другую группу" из ТЗ.
3. Как и файловые операции — мутации `groups.json` идут через `pendingCmd`,
   не напрямую из HTTP-хендлера (тот же принцип, что и с SD_MMC файлами —
   `groups.json` тоже File на SD, тот же риск гонки при параллельной записи).
4. Хранить в оперативной памяти закэшированную структуру групп (аналогично
   `trackList` в audio_test), перечитывать `groups.json` только при
   изменениях, не на каждый HTTP-запрос статуса.

## Открытые вопросы

- Нет.

## Критерии готовности

- Группы создаются/переименовываются/удаляются, трек можно переносить между
  группами, изменения переживают перезагрузку устройства (валидный
  `groups.json` на SD).

## Как реализовано

- Отдельный модуль `groups.h/cpp` (не внутри `storage.cpp`, как
  предполагалось в черновике плана изначально) — чтобы `storage.cpp` не знал
  про группы вообще; синхронизация между ними (удаление/переименование трека
  → снять/перенести assignment) сделана в `servers.cpp::processPendingCommands`,
  по тому же принципу, что и `stopAudio()` при удалении играющего трека.
- JSON — через `ArduinoJson@^7` (новая зависимость в `platformio.ini`), не
  вручную конкатенацией строк — заодно тем же способом переписан и
  `/api/status` (был потенциально ломающийся JSON при спецсимволах в имени
  файла).
- API — `GET /api/groups`, `POST /api/groups/create|rename|delete`,
  `POST /api/tracks/assign_group` (`group=""` — снять группу). Мутации — та
  же `pendingCmd`-очередь, что и файловые операции (см. `CLAUDE.md` §4.2).
- Валидация на устройстве: имя группы 1..64 символов, `assign_group`
  проверяет существование и группы, и трека (`trackList`) до постановки в
  очередь.
- `pio run` — зелёно (RAM 18.2%, Flash 28.4%). Проверка на реальном железе —
  план 17.
