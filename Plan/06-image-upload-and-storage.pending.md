# 06. Загрузка и хранение картинок треков

**Статус:** pending
**Обновлено:** 2026-07-27
**Проект:** device + frontend
**Зависит от:** 04

## Цель

Дать возможность прикрепить картинку к треку (из буфера обмена, камеры или
файла на телефоне) с хранением на SD-карте устройства (согласованное решение,
см. `CLAUDE.md` §2.2).

## Детали

### Фронтенд

1. Три источника картинки на плитке трека:
   - **Вставка из буфера обмена** (`paste` event, `ClipboardEvent.clipboardData`)
     — самый быстрый способ на десктопе/при копировании скриншота.
   - **Камера** — `<input type="file" accept="image/*" capture="environment">`
     — на мобильном открывает камеру напрямую.
   - **Файл с устройства** — обычный `<input type="file" accept="image/*">`
     без `capture`, для выбора существующего фото из галереи.
2. **Обязательный ресайз на канвасе перед отправкой** — не отправлять на
   устройство оригинал в полный размер (телефонные фото — по 3-10МБ, SD и
   HTTP-стек ESP32 не должны с этим работать). Целевой размер — по длинной
   стороне ~480-600px, JPEG quality ~80%, через `<canvas>` +
   `toBlob('image/jpeg', 0.8)`.
3. `POST /api/tracks/image` — multipart или raw body с именем файла-трека в
   query/заголовке, картинка после ресайза (десятки КБ, не мегабайты).

### Устройство

1. Хранить картинки на SD в отдельной директории (например `/images/`,
   реальная FAT-директория — тут директории уместны, в отличие от группировки
   треков, картинки физически привязаны к конкретному треку 1:1, не нужен
   индекс). Имя файла картинки = имя трека + `.jpg` (детерминированная связь,
   не нужна отдельная таблица соответствий).
2. `GET /images/<track>.jpg` — раздача статикой через `AsyncWebServer`
   (`server.serveStatic` на директорию, самый простой вариант).
3. Заложить лимит на размер загружаемого файла на уровне HTTP-хендлера (не
   доверять фронтенду, что он всегда ресайзнёт) — отклонять body больше
   разумного порога (например 500КБ) с понятной ошибкой.
4. Учесть в бюджете SD-карты: 16MB flash + отдельная SD-карта для
   треков/картинок (уточнить объём карты, не критично для плана, но стоит
   иметь в виду при расчёте, сколько треков+картинок влезет).

## Открытые вопросы

- Нет — оба конца понятны, decision по хранению уже принят.

## Критерии готовности

- Можно прикрепить картинку всеми тремя способами с мобильного браузера.
- Картинка переживает перезагрузку устройства, отображается в плитке.
